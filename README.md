# Atlas

[![CI](https://github.com/andy23512/atlas/actions/workflows/ci.yml/badge.svg)](https://github.com/andy23512/atlas/actions/workflows/ci.yml)

An unofficial learning roadmap for CharaChorder 3D input devices (CharaChorder
One, CharaChorder Two, CCU, and Master Forge).

## Links

- [Website](https://andy23512.github.io/atlas/)

## About

Atlas ties together the other unofficial CharaChorder tools and Tangent's blog
posts into a single step-by-step path: memorizing the layout before a device
arrives, a first guided tutorial, practicing character entry, practicing
chorded entry, and a list of other tools worth knowing about once you're up
and running.

## Development

```bash
npm install
npm run dev     # serve locally
npm run build   # production build
```

Deployment to GitHub Pages runs automatically on every push to `main` (see
`.github/workflows/deploy.yml`).
